# ROBO001 2026–2027 – Bài 4: Mô Phỏng Động Học (Kinematics)

Nhánh **`Lesson4_Dong_Hoc`** chứa bộ 3 mô phỏng tương tác 2D phục vụ giảng dạy **Bài 4 (Slides 12, 13, 14)** của khóa **ROBO001** năm học 2026–2027.

## Danh sách các tệp mô phỏng

| Tệp | Nội dung bài học |
|---|---|
| [`He_Truc_Oxy.html`](./He_Truc_Oxy.html) | **Slide 12**: Hệ trục tọa độ Oxy & mối quan hệ giữa bán kính R với Ox, Oy trên đường tròn (`x = R·cosθ`, `y = R·sinθ`) |
| [`Chuyen_Dong_Thang.html`](./Chuyen_Dong_Thang.html) | **Slide 13**: Chuyển động thẳng đều – quan hệ vận tốc, quãng đường, thời gian (`v = s / t`, `s = v · t`) |
| [`Chuyen_Dong_Quay.html`](./Chuyen_Dong_Quay.html) | **Slide 14**: Chuyển động quay (`ω = φ / t`), bánh xe lăn không trượt (`v = ω · R`), quỹ đạo Cycloid & sai số động cơ VEX IQ |
| [`index.html`](./index.html) | Trang danh mục tổng hợp mở nhanh 3 phần mô phỏng |
| [`style.css`](./style.css) | Bảng kiểu giao diện chung |
| [`assets/`](./assets) | Thư mục chứa hình ảnh logo, linh vật và dữ liệu ảnh độc lập |

## Cách sử dụng

1. Chọn nhánh **`Lesson4_Dong_Hoc`** ở góc trên bên trái trang repo.
2. Bấm **Code → Download ZIP** và giải nén về máy tính.
3. Mở trực tiếp tệp **`He_Truc_Oxy.html`**, **`Chuyen_Dong_Thang.html`**, hoặc **`Chuyen_Dong_Quay.html`** bằng trình duyệt web bất kỳ (Chrome, Edge, Safari...) để trình chiếu trên lớp.
